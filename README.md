## Core Concepts

Start here: two ideas, one flow

### 🧰 Git

Software on **your computer** that remembers every version of your files.

### ☁️ GitHub

A website that **stores your Git projects online** so you can share and team up.

### 🛤️ The journey of a change

📝**Working Directory***you edit files*

*➡️*`git add`

🛒**Staging Area***ready to save*

*➡️*`git commit`

🗄️**Local Repo***saved on your PC*

*➡️*`git push`

☁️**GitHub***online backup*

🌿 **Branching** lets you build a new feature safely on the side, without touching your working (production) code.

## Step-by-Step Practice

Tap each step as you finish it

[ ] 📁 **Create a folder** on your computer and open it in the terminal or VS Code. [ ] 🎬 Run `git init` to make it a Git repository. [ ] 📄 Create a file like `app.js` or `index.html`, then run `git status`. [ ] 💾 Stage with `git add .` and save with `git commit -m "Initial commit"`. [ ] 🌱 Run `git checkout -b feature-test`, edit a file, and commit on that branch. [ ] 🔀 Go back with `git checkout main`, then `git merge feature-test`. [ ] 🚀 Create an empty repo on GitHub, run `git remote add origin`, then `git push -u origin main`.

🎉 Finished all 7? You’ve practiced the complete local-to-remote cycle!
